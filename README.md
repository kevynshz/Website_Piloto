# Website_Piloto

#website piloto, feito inicialmente com html e css basico, será usado como modelo escalonavel a longo prazo.

## Aurora Residences

A interface agora representa uma comunidade de condomínio de luxo, com entrada,
feed de moradores, mural de avisos ilustrativos e apresentação dos espaços.
As contas, publicações e comentários continuam usando as mesmas chaves locais
para preservar os cadastros existentes. As fotografias são carregadas do
Unsplash e precisam de conexão com a internet. Os avisos são exemplos fixos;
não representam comunicados reais nem um painel administrativo.
